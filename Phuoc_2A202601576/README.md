# Phần Cá Nhân Của Phước

Thư mục này gom toàn bộ phần việc cá nhân của Ngô Minh Phước để tiện chia sẻ và đối chiếu.

## Nội dung

- `REPORT_CANHAN.md`: báo cáo cá nhân đã điền.
- `src/`: bản sao các file code cá nhân đã hoàn thiện trong `src/`.

## Ghi chú

- Code chính thức của repo vẫn nằm ở thư mục gốc `src/`.
- Dữ liệu chính thức của repo nằm ở thư mục gốc `data/k4_ecommerce/`.
- Thư mục này chỉ giữ phần riêng của Phước để thể hiện rõ phần cá nhân.
